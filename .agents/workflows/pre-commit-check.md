---
description: 변경 사항을 커밋하기 전, 린트/빌드 체크 및 보안 검수를 통해 코드의 안정성을 확보하고 최적화된 한국어 커밋 메시지를 생성하는 루틴입니다.
---

1. TypeScript 오류를 확인합니다. `npx tsc --noEmit`
2. ESLint를 통해 코드 스타일과 잠재적 버그를 검사합니다. `npm run lint`
3. 애플리케이션이 정상적으로 빌드되는지 확인합니다. 빌드 스크립트 실행. `npm run build`
4. 위의 과정이 모두 문제없이 통과되면, 변경 사항의 목적과 내용을 바탕으로 적절한 한국어 커밋 메시지를 생성하고 제안합니다.
5. 제안한 커밋 메시지를 바탕으로 변경 사항에 대한 브리핑을 진행합니다.
